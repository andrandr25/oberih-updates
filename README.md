# Mudi Core update feed

Signed packages for Mudi Core (luci-app-mudi) on GL.iNet GL-E750 routers.
Routers verify `Packages.sig` (usign key `87d48f5e9a5bb4a9`, see `mudi-feed.pub`)
and the package SHA256 before installing. Unsigned or modified files are refused.

Channels: `stable/`, `beta/`. Proprietary software — see the LICENSE in each package.
