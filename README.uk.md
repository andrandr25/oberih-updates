# Фід оновлень Mudi Core

[English](README.md) | **Українська**

Підписані пакети Mudi Core (`luci-app-mudi`) для роутерів GL.iNet GL-E750 (Mudi V2).

## Встановлення

Заводська прошивка GL 4.x, роутер має інтернет:

1. Адмін-панель `http://192.168.8.1` → **Applications → Plug-ins → Sources** → **Add**:
   назва `mudi`, URL `https://git.fraola.net/androffka/mudi-updates/raw/branch/main/stable`
2. **Update** — оновити списки пакетів.
3. Знайти `luci-app-mudi` → **Install**.
4. Оновити сторінку — у лівому меню з'явиться **Mudi Core**. Оновлення далі приходять самі.

## Безпека

Перед встановленням роутер перевіряє `Packages.sig` зафіксованим ключем `87d48f5e9a5bb4a9` (див. `mudi-feed.pub`) і SHA256 кожного пакета. Непідписані або змінені файли відхиляються.

| Тека | Що |
|---|---|
| `stable/` | випуски для всіх |
| `beta/` | ранній доступ |
| `extras/` | Blue Merle і його залежності для встановлення в один клік (незмінені пакети, див. `extras/SOURCES.txt`) |

Blue Merle змінює IMEI модема; у деяких країнах це заборонено або регулюється законом. Mudi Core встановлює його лише після того, як ви підтвердите це попередження.
